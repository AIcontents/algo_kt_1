# КТ1: решения на Java

Шесть задач, каждая — один самодостаточный файл `Main.java`: только стандартная библиотека, ввод из stdin, вывод в stdout, совместимо с Java 8 и новее. В начале каждого файла — комментарий с идеей решения и оценкой сложности.

## Структура

```
task3/Main.java        решение задачи 3
task3/examples/        примеры: 1.in / 1.out, 2.in / 2.out, 3.in / 3.out
```

## Запуск

```
cd task3
javac Main.java
java Main < examples/1.in
```

В проверяющую систему отправляйте `Main.java` из нужной папки (класс называется `Main`).

## Допущения

1. Формат ввода — как в условии: массив записью `[1, 2, 3]`; в задаче 4 две строки `nums = [...]` и `k = ...`; в задаче 6 — `source = "..."` и `target = "..."` (кавычки необязательны).
2. Вывод — как в примерах условия (задача 2: `[[-1, -1, 2], [-1, 0, 1]]`, задача 6: строка в кавычках).
3. Методы (`longestConsecutive`, `threeSum`, …) — статические функции с «литкодовскими» сигнатурами, их можно перенести в `class Solution`.

## Задачи

| № | Задача | Идея | Сложность |
|---|---|---|---|
| 1 | Самая длинная последовательность подряд идущих чисел | множество; цепочка начинается с x, если нет x-1 | O(n) |
| 2 | Тройки с нулевой суммой | сортировка + два указателя, пропуск повторов | O(n²) |
| 3 | Самый длинный участок с ≤ 2 типами | скользящее окно | O(n) |
| 4 | Подмассивы с суммой k | префиксные суммы + хеш-таблица, ответ в `long` | O(n) |
| 5 | Контейнер с водой | два указателя, двигаем меньшую стенку | O(n) |
| 6 | Минимальная подстрока-покрытие | скользящее окно со счётчиками | O(\|s\|+\|t\|) |

## Как проверялось

- Каждая из шести программ сверена с простым перебором на Python на 200–300 случайных мелких тестах (плюс примеры из условия и граничные случаи).
- Для задач 1, 4, 5 — отдельные тесты со значениями до 10⁹ по модулю, чтобы поймать переполнение `int`.
- Входы максимального размера из ограничений запускались с `-Xmx256m`: каждая программа укладывается примерно в 0,7 с на одном ядре; результаты сверялись с независимыми реализациями на Python/numpy.
- Все примеры из папок `examples/` прогнаны на чистой сборке.
